# MAYURA 1989 Bar & Kitchen

**ಮಯೂರ ೧೯೮೯ ಬಾರ್ ಮತ್ತು ಕಿಚನ್**

A luxury rooftop restaurant and modern bar website for **MAYURA 1989 Bar & Kitchen**, located in Rajajinagar, Bengaluru.

## Features

- **Luxury Rooftop & Bar Aesthetic**: Premium dark charcoal, amber gold accents, smooth glassmorphism, and responsive layouts.
- **Cinematic Hero**: Ambient showcase, Google rating badge (4.0★ / 7,255+ reviews), quick action CTAs.
- **Interactive Menu**: Categorized dishes (Andhra Specials, Biryanis, Starters, Main Course, Beverages), search filter, dietary indicators (Veg / Non-Veg).
- **Online Reservation System**: Table reservation modal with form validation and confirmation.
- **Photo Gallery & Lightbox**: Categorized view of food, drinks, rooftop ambience, and interiors.
- **Full Contact & Google Map Integration**: Address, timings, phone quick-call, and directions.
- **SEO & Schema.org**: Fully optimized Open Graph tags and JSON-LD Restaurant structured data.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
